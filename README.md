# RAD Implementation Project

Implementation of two data stream analysis algorithms:
- **Hashing with Chaining** for exact second moment calculation
- **Count-Sketch** for approximate second moment estimation

## Requirements
- .NET 9.0 SDK

## How to Run
Clone the repository and run:
```bash
git clone https://github.com/TobyDIKU/RAD-Project
cd RAD-Project
dotnet run
```

## Output
During execution, intermediate results are written to CSV files which can be used for further analysis and plotting. These can be analysed using e.g. R or any other data analysis tool of your choice.
